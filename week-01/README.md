# Week 1: Cloud Fundamentals & Account Setup

The root user is the login created when I opened the AWS account, and it has unlimited access to everything, including billing and closing the account. Because that power can't be limited, I enabled MFA on it and only use it for the rare tasks that require root. An IAM user is a separate identity inside the account that I create for daily work, and its permissions come only from the policies I attach, such as AdministratorAccess for my admin user. IAM users can have their own CLI access keys, so I never need to create root access keys. If an IAM user's keys leak, I can deactivate them without putting the whole account at risk. The Shared Responsibility Model splits security between AWS and me. AWS secures the cloud itself, which means the physical data centers, hardware, and the underlying network and services. I secure what I put in the cloud, such as my IAM permissions, MFA, data, and configurations.
